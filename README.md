# LoL アイテムビルドアドバイザー

自分のチャンピオンと敵チーム（最大5人）を選ぶと、**敵構成に合わせたアイテム購入順序**を提案する Web アプリ。
Riot 公式 **Data Dragon** のみを使用（完全無料・規約クリア・最新パッチに自動追従）。

## 仕組み（全チャンピオン対応）
1. Data Dragon からチャンピオン / アイテムデータを取得（チャンピオン名・アイテム名は日本語）
2. 各チャンピオンの「型（アーキタイプ）」を `tags` + `info` から自動判定
   - AD マークスマン / AP メイジ / AD・AP アサシン / AD・AP ファイター / タンク / エンチャンター / タンクサポート
3. 型ごとの**ベースビルド雛形**を適用
4. 敵チームの**脅威プロファイル**を集計（物理/魔法比率・タンク数・CC数・回復数）
5. プロファイルに応じて**対抗アイテム**を差し込み、購入順に整形

### 対抗ロジックの例
- 敵に回復持ち → 回復カット（モータルリマインダー / モレロノミコン / ソーンメイル 等）
- 敵にタンクが多い → 貫通・割合ダメージ（ドミニクリガード / ヴォイドスタッフ 等）
- 敵が物理寄り → 物理防御、魔法寄り → 魔法防御
- 敵にCCが多い → テナシティ / CC解除（マーキュリー / マーキュリアルシミター 等）

## 開発
```bash
npm install
npm run dev      # 開発サーバ
npm run build    # 本番ビルド（dist/）
```

## 既知の制限・調整ポイント
- ビルドは「型ベース」のため、チャンピオン専用のプロビルドほど精密ではない
- CC量 / 回復量は Data Dragon に無いため `src/gameData.ts` の手動リストで判定（新チャンピオンは追記が必要）
- フレックスキャラの型誤判定は `src/classify.ts` の `OVERRIDES` で補正
- ベースビルドや対抗ルールは `src/builds.ts` / `src/counter.ts` で調整可能

## 構成
| ファイル | 役割 |
|---|---|
| `src/ddragon.ts` | Data Dragon 取得・アイテム名解決 |
| `src/classify.ts` | チャンピオンの型・ダメージタイプ判定（＋例外上書き）|
| `src/gameData.ts` | CC / 回復の手動マスタ |
| `src/builds.ts` | 型ごとのベースビルド雛形 |
| `src/counter.ts` | 脅威プロファイル算出・対抗アイテム選定 |
| `src/recommend.ts` | 最終的なビルド組み立て |
| `src/components/` | UI（チャンピオン選択 / 結果表示）|
